# نظام حجز المواعيد (Appointment Booking System)

> A web-based appointment booking system for small clinics. Patients browse
> available time slots and book or cancel online; admins manage services,
> working hours, and bookings from a dashboard. Built end-to-end following
> the Software Development Life Cycle (SDLC) as a solo project.

## نظرة عامة (Overview)
العيادات الصغيرة (طبيب واحد إلى ثلاثة أطباء) بتدير مواعيدها غالباً
بالتلفون أو الواتساب، وهاد بيسبب حجوزات متعارضة، ومواعيد منسية،
ووقت ضايع من السكرتارية بالرد على نفس الأسئلة (شو المتاح؟ كم السعر؟).

هذا النظام بيخلّي المريض يشوف الأوقات المتاحة ويحجز أو يلغي أونلاين
بدون مكالمة، وبيعطي الأدمن لوحة تحكم لإدارة الخدمات وساعات الدوام
والحجوزات، مع ضمان تقني إنه **ما يصير حجزين لنفس الوقت أبداً**.

## الأهداف القابلة للقياس (Goals)
- المريض يكمّل الحجز بأقل من دقيقتين وبدون حساب مسبق معقّد.
- صفر حجوزات متعارضة (Double Booking) حتى لو ضغط مستخدمين بنفس اللحظة.
- الأدمن يشوف جدول اليوم بنظرة وحدة.

## غير الأهداف (Non-Goals)
- مش نظام سجلات طبية (EMR) ولا بيخزّن معلومات تشخيص.
- مش منصة متعددة العيادات (Multi-tenant) بالنسخة 1.
- مش بديل عن أنظمة المحاسبة.

## المستخدمون (Personas)
- **المريض (Customer):** بدو يحجز بسرعة من الموبايل، غالباً ما بدو ينشئ حساب
  ويتذكر باسوورد جديد.
- **الأدمن / السكرتارية (Admin):** بدو يشوف جدول اليوم، يضيف أو يلغي حجز يدوي
  (مكالمة تلفون)، ويغيّر ساعات الدوام والإجازات.
- **مزوّد الخدمة (Provider):** الطبيب. بالنسخة 1 هو مجرد "مورد" له جدول،
  بدون واجهة خاصة فيه.

## النطاق (Scope) - ترتيب MoSCoW

### Must (النسخة 1، بدونها النظام ما بيشتغل)
- تسجيل مستخدم وتسجيل دخول (Email + Password)
- نظام أدوار: Customer / Admin
- إدارة الخدمات (اسم، مدة، سعر للعرض فقط)
- تعريف ساعات الدوام الأسبوعية لكل Provider
- عرض الأوقات المتاحة (Available Slots) حسب الخدمة والتاريخ
- إنشاء حجز مع **منع التعارض**
- إلغاء الحجز من المريض
- لوحة أدمن: جدول اليوم، قائمة الحجوزات، إلغاء/إنشاء حجز يدوي

### Should (إذا ضل وقت بالنسخة 1)
- تعديل موعد (Reschedule)
- إجازات واستثناءات بالجدول (يوم عطلة)
- فلترة وبحث بحجوزات الأدمن

### Could (النسخة 2)
- تذكير بالإيميل أو SMS
- حجز بدون حساب (Guest Booking) برابط تأكيد
- تقويم بصري (Calendar View)

### Won't (خارج النطاق حالياً)
- دفع أونلاين
- تطبيق موبايل أصلي
- تعدد العيادات (Multi-tenant)
- تعدد اللغات
- تكامل مع Google Calendar

## افتراضات وقيود (Assumptions & Constraints)
- عيادة وحدة، منطقة زمنية وحدة (تُخزّن الأوقات بـ UTC وتُعرض بتوقيت العيادة).
- الموعد بيحجز Slot كامل حسب مدة الخدمة، بدون تداخل.
- المطوّر شخص واحد، المدة 5-6 أسابيع.

## المخاطر الأساسية (Key Risks)
| الخطر | التخفيف |
|---|---|
| Race condition عند الحجز المتزامن | Unique constraint أو transaction بقاعدة البيانات + اختبار مخصص |
| تضخم النطاق (Scope Creep) | أي ميزة جديدة تروح لـ Backlog وما تدخل إلا بعد النسخة 1 |
| أخطاء المناطق الزمنية | UTC بالتخزين، وتحويل واحد فقط عند العرض |
